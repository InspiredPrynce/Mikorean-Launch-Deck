**Unique Link Generation:**

**Tracking Infrastructure:**
- UTM parameters on all referral links
- Cookie duration: 30 days (first-click attribution)
- Cross-device tracking via WhatsApp phone number matching
- Real-time referral dashboard in customer account

### Referral Fraud Prevention

| Fraud Type | Detection Method | Prevention |
|------------|------------------|------------|
| Self-referral | IP + device fingerprint matching | Block same-device referrals |
| Referral farming | Velocity checks (referrals/hour) | Cap at 10 referrals/day/account |
| Fake accounts | Phone number verification required | OTP verification before credit issued |
| Return abuse | Refund on referred purchase = credit revoked | 30-day hold on referral credits |
| Bot referrals | CAPTCHA + behavioral analysis | Rate limiting on link generation |

## 1.2 Viral Loops for Tech Accessories

### Loop 1: The "Unboxing Share" Loop

```
Product Arrives → Premium Packaging → QR Code on Box →
"Scan to share your unboxing" → Auto-generates TikTok/IG story template →

```


- Incentive: Setup transformation winners get featured + ₦10,000 credit

```
Customer Has Tech Problem → Mikorean Solves It → Customer Tells Friends →

```

**Execution:**
- Create relatable "tech problem" content (dead battery in Lagos traffic, broken cables)

## 5.3 Fraud Prevention

### Fraud Detection Rules

| Rule | Trigger | Action |
|------|---------|--------|
| Self-referral | Same IP + device fingerprint | Block referral credit |
| Velocity limit | >10 referrals/hour | Flag for review |
| Fake accounts | Phone number not verified | Block credit until verified |
| Return abuse | Referee returns product | Revoke referrer credit |
| Bot activity | Unusual click patterns | Rate limit + CAPTCHA |
| Multiple accounts | Same phone number, different emails | Merge accounts, block duplicate credits |

### Fraud Prevention Infrastructure

| Layer | Mechanic | Implementation |
|-------|----------|----------------|
| **Prevention** | Phone number verification | OTP required for account creation |
| **Detection** | IP + device fingerprinting | Track referral sources |
| **Monitoring** | Velocity checks | Real-time referral rate monitoring |
| **Response** | Manual review queue | Flag suspicious referrals for CS review |
| **Recovery** | Credit reversal | Revoke credits for fraudulent referrals |

### Fraud Response Playbook

```
SUSPECTED FRAUD DETECTED
│
├─ LEVEL 1: Automated block
│  ├─ Referral credit held (not issued)
│  ├─ Account flagged for review
│  └─ CS notified via dashboard
│
├─ LEVEL 2: Manual review
│  ├─ CS agent investigates
│  ├─ Contact referrer if needed
│  └─ Decision: approve, decline, or escalate
│
├─ LEVEL 3: Escalation
│  ├─ CS manager review
│  ├─ Account suspension if confirmed fraud
│  └─ Legal action if significant fraud
│
└─ LEVEL 4: System improvement
   ├─ Update fraud rules
   ├─ Add new detection patterns
   └─ Report to product team
```

# 8. METRICS & DASHBOARD

## 8.1 North Star Metric Definition

### Primary North Star Metric

**"Monthly Active Paying Customers" (MAPC)**

**Definition:** The number of unique customers who make at least one purchase in a given month.

**Why This Metric:**
1. Directly measures growth (new customers + repeat customers)
2. Tied to revenue (paying = revenue)
3. Captures retention (repeat purchases)
4. Simple to understand and communicate
5. Actionable (can be influenced by acquisition, activation, retention)

**Target Trajectory:**

| Month | MAPC Target | Growth Rate |
|-------|-------------|-------------|
| Month 1 | 10,000 | — |
| Month 2 | 15,000 | +50% |
| Month 3 | 22,500 | +50% |
| Month 6 | 50,000 | +40%/month |
| Month 12 | 100,000 | +30%/month |

### Supporting Metrics (Growth Model)

```
                    NORTH STAR: MAPC
                          │
          ┌───────────────┼───────────────┐
          │               │               │
     ACQUISITION      ACTIVATION      RETENTION
          │               │               │
    ┌─────┴─────┐   ┌─────┴─────┐   ┌─────┴─────┐
    │           │   │           │   │           │
 Website    Referral First    Cart   Repeat    Loyalty
 Visitors   Program  Purchase Recovery Purchase  Program
    │           │       │       │       │         │
 Traffic   Referral  Conversion Conversion LTV   Points
   CAC      Rate      Rate      Rate    Growth  Redemption
```

### North Star Calculation

```
MAPC = New Customers + Repeat Customers

New Customers = Website Visitors × Traffic-to-Customer Conversion Rate
Repeat Customers = Previous Month MAPC × Retention Rate

Example (Month 2):
- Website Visitors: 500,000
- Traffic-to-Customer Conversion Rate: 3%
- New Customers: 500,000 × 3% = 15,000
- Previous Month MAPC: 10,000
- Retention Rate: 30%
- Repeat Customers: 10,000 × 30% = 3,000
- MAPC: 15,000 + 3,000 = 18,000
```
