# APPENDIX A: GLOSSARY

| Term | Definition |
|---|---|
| **PD (Power Delivery)** | USB-C fast-charging standard that negotiates optimal voltage/current |
| **QC (Quick Charge)** | Qualcomm fast-charging standard |
| **GaN (Gallium Nitride)** | Chipset material that runs cooler and smaller than silicon |
| **ANC (Active Noise Cancellation)** | Technology that uses microphones to cancel ambient noise |
| **LDAC** | Sony-developed hi-res audio codec (up to 990kbps) |
| **TWS (True Wireless Stereo)** | Earbuds with no wires between buds or to phone |
| **UN38.3** | UN safety test for lithium batteries (airline requirement) |
| **IPX5** | Water resistance rating (protected against water jets) |
| **IP68** | Dust-tight + protected against submersion |
| **5ATM** | Water resistance to 50 meters (swimming safe) |
| **PPG** | Photoplethysmography — optical heart rate sensor |
| **SpO2** | Blood oxygen saturation measurement |
| **Li-Polymer** | Lithium-Polymer battery (lighter, more flexible than Li-ion) |
| **TR90** | Thermoplastic material used in lightweight eyeglass frames |
| **Enc (Environmental Noise Cancellation)** | Technology that filters background noise during calls |
| **Multipoint** | Bluetooth feature allowing connection to 2 devices simultaneously |
| **Passthrough Charging** | Ability to charge the power bank while it charges a device |
| **Qi** | Wireless charging standard |
| **Qi2** | Next-gen wireless charging (magnetic alignment, faster) |
| **MagSafe** | Apple magnetic wireless charging system |
| **AMOLED** | Display technology with individual pixel illumination (deeper blacks) |
| **Neodymium** | Rare-earth magnet material used in high-quality audio drivers |
