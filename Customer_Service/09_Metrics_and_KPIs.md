| Metric | Target | Measurement |

### CSAT by Channel Targets

| Channel | Target CSAT |
|---------|-------------|
| WhatsApp | >= 4.3 / 5.0 |
| Instagram DM | >= 4.1 / 5.0 |
| Email | >= 4.0 / 5.0 |
| Phone | >= 4.4 / 5.0 |
| Marketplace (Jumia/Konga) | >= 4.0 / 5.0 |

### CSAT Improvement Actions

| CSAT Range | Action |
|------------|--------|
| >= 4.5 | Recognize agent, share as best practice |
| 4.0–4.4 | Maintain, minor coaching |
| 3.5–3.9 | Targeted coaching, process review |
| < 3.5 | Immediate intervention, retraining, root cause analysis |

## 9.2 First Response Time (FRT) Targets

| Channel | Target FRT | Acceptable Max |
|---------|-----------|----------------|
| WhatsApp | < 5 minutes | 10 minutes |
| Instagram DM | < 15 minutes | 30 minutes |
| Email | < 2 hours | 4 hours |
| Phone | < 30 seconds | 60 seconds |
| Jumia Chat | < 1 hour | 2 hours |
| Konga Chat | < 1 hour | 2 hours |

### FRT Tracking Rules

- Measured from customer's first message to agent's first response
- Auto-replies do NOT count as first response
- After-hours messages measured from next business hour opening
- FRT tracked per agent and per channel

## 9.8 Continuous Improvement Framework

### Monthly Review Process

1. **Collect data:** Pull all metrics for the month
2. **Analyze trends:** Compare to targets and previous months
3. **Identify gaps:** Where are we underperforming?
4. **Root cause analysis:** Why are the gaps occurring?
5. **Action planning:** What specific steps will fix the gaps?
6. **Assign ownership:** Who is responsible for each action?
7. **Track progress:** Follow up weekly on action items

### Quarterly Optimization

1. **Review all metrics** against quarterly targets
2. **Customer feedback analysis** — common themes and requests
3. **Agent feedback** — what's working, what's not
4. **Process updates** — simplify, automate, or eliminate
5. **Training needs** — address skill gaps
6. **Technology review** — tools and systems optimization
7. **Budget adjustment** — reallocate based on performance

### Annual Strategic Planning

1. **Year-in-review** — full performance assessment
2. **Customer satisfaction benchmarking** — industry comparison
3. **Team structure review** — hiring needs, role adjustments
4. **Technology roadmap** — CRM, automation, AI tools
5. **Budget planning** — next year's CS budget
6. **Goal setting** — SMART goals for the coming year
